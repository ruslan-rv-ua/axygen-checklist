# Доменні документи

Як навички мають читати доменну документацію цього репозиторію, перш ніж
досліджувати код.

## Що прочитати перед дослідженням

- [`docs/requirements.md`](../requirements.md) — специфікація, єдине джерело правди про поведінку. Нормативна вона; документи нижче її не заступають.
- **`CONTEXT.md`** у корені репозиторію, або
- **`CONTEXT-MAP.md`** у корені, якщо він є — він указує на `CONTEXT.md` кожного контексту; читати ті, що стосуються теми.
- **`docs/adr/`** — ADR, які зачіпають ділянку роботи. У багатоконтекстних репозиторіях перевіряти ще й `src/<context>/docs/adr/`.

Якщо якогось із цих файлів немає, **мовчки йти далі**: не повідомляти про
відсутність і не пропонувати створити їх наперед. Навичка `/domain-modeling`
(доступна через `/grill-with-docs` і `/improve-codebase-architecture`) створює
їх ліниво — тоді, коли терміни чи рішення справді доводиться закріпити.

## Структура файлів

Одноконтекстний репозиторій (наш випадок):

```
/
├── CONTEXT.md
├── docs/adr/
│   ├── 0001-focus-stays-on-tested-app.md
│   └── 0002-filter-as-visibility-predicate.md
└── addon/
```

Багатоконтекстний репозиторій (у корені є `CONTEXT-MAP.md`):

```
/
├── CONTEXT-MAP.md
├── docs/adr/                          ← загальносистемні рішення
└── src/
    ├── ordering/
    │   ├── CONTEXT.md
    │   └── docs/adr/                  ← рішення конкретного контексту
    └── billing/
        ├── CONTEXT.md
        └── docs/adr/
```

## Вживай словник глосарію

Коли у твоєму результаті названо доменне поняття (заголовок задачі, пропозиція
рефакторингу, гіпотеза, назва тесту), вживай термін так, як його означено в
`CONTEXT.md`. Не зісковзуй на синоніми, яких глосарій свідомо уникає.

Якщо потрібного поняття в глосарії ще немає — це сигнал: або ти вигадуєш мову,
якої проєкт не вживає (варто передумати), або є справжня прогалина (занотуй її
для `/domain-modeling`).

## Позначай конфлікти з ADR

Якщо результат суперечить наявному ADR, скажи про це прямо, а не мовчки його
обходь:

> _Суперечить ADR-0002 (фільтр як предикат видимості) — але варто перевідкрити, бо…_
