# Мітки тріажу

Навички говорять про п'ять канонічних ролей тріажу. Цей файл зіставляє ролі з
реальними рядками міток у трекері цього репозиторію.

| Роль у mattpocock/skills | Мітка в нашому трекері | Значення                            |
| ------------------------ | ---------------------- | ----------------------------------- |
| `needs-triage`           | `needs-triage`         | Супровідник має оцінити задачу      |
| `needs-info`             | `needs-info`           | Чекаємо подробиць від автора звіту  |
| `ready-for-agent`        | `ready-for-agent`      | Повністю описана, готова AFK-агенту |
| `ready-for-human`        | `ready-for-human`      | Потребує людської реалізації        |
| `wontfix`                | `wontfix`              | Не робитимемо                       |

Коли навичка згадує роль (наприклад, «постав мітку готовності для AFK»), бери
відповідний рядок мітки з цієї таблиці.

Самі рядки міток — ідентифікатори, а не текст, і не перекладаються. Праву
колонку правлять лише тоді, коли трекер уже вживає інші назви.
