# Axygen Checklist

Додаток NVDA для тестувальників, які працюють на слух.

Axygen Checklist проводить тестувальника чеклістом за допомогою глобальних
команд, лишаючи системний фокус у тестованому застосунку. Пункт можна
позначити як пройдений, провалений або пропущений, прокоментувати, прослухати
чи прибрати фільтром — не полишаючи вікна, яке саме перевіряють.

Чекліст — це звичайний файл JSON. Він містить пункти для перевірки, а після
прогону — і результат кожного з них, тож прогін можна передати іншій людині,
зберегти поруч зі збіркою, якої він стосується, або повторити пізніше.

Додаток на ранньому етапі розробки. Команди, озвучення та формат файлу ще
реалізуються — нічого з цього поки не є сталим.
